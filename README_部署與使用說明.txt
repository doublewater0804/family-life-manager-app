家庭生活管理 APP V2.1｜Spark 免費版｜部署與更新說明

一、重要資訊
Firebase 專案：family-life-manager-694c7（不要操作原 EHS 專案 esh-v85）。
現有 GitHub 儲存庫：doublewater0804/family-life-manager-app
正式網址：https://doublewater0804.github.io/family-life-manager-app/
本版本沿用原有家庭資料路徑：families/home/bills、events、templates、members。
現有登入帳號、家庭成員 UID 及已儲存的共用資料都保留。

二、正式更新前：必做備份
1. 先登入目前運作中的 V2.0 APP，進入設定 → 家庭共用 → 匯出 JSON，將備份存妥。
2. 若有私人資料，請由各家庭成員分別登入舊版「我的私人」並匯出 JSON；不得直接讓其他人讀取。
3. Firebase Firestore 規則先不要修改。請保留原本管理者與成員文件。

三、GitHub 更新方式
1. 解壓縮本 ZIP。
2. GitHub 進入 doublewater0804/family-life-manager-app → Add file → Upload files。
3. 將本 ZIP 中全部 11 個檔案（而不是 ZIP 本身）上傳到儲存庫根目錄，覆蓋同名檔案。
   注意：GitHub 網頁上傳若同名未直接覆蓋，請使用 Edit file／其他 Git 客戶端更新，不要產生第二份相同名稱的檔案。
4. Commit changes，確認 GitHub Actions 的 pages build and deployment 成功。
5. 使用 APP 網址重新整理；若仍顯示舊版，關閉 APP 後重開或清除舊 Service Worker 快取。不要任意清除 Safari 所有網站資料。
6. 本次不需建立新 Firebase 專案，也不需把 firestore.rules 檔部署到 GitHub Pages（它只是部署時比對的參考文件）。

四、V2.1 使用方式
首頁：顯示全年 12 個月（3 欄×4 列）、每個月份繳費項目、已繳狀態、未繳到期日、記事數。
月份：點選月份 → 未繳費（含期限、金額）、已繳費（含繳費日、金額）、所有記事。
設定 → 繳費基本資料管理：所有家庭成員均可新增、編輯、停用固定繳費項目；週期每月／每兩個月／每季／半年／年。
當月新增繳費：可選既有項目帶入名稱、分類、預設金額，也可建立一次性項目。
注意：固定項目的「首次繳費期限」同時作為往後各期的起算日期。系統建立的每期紀錄可再個別修改金額或期限。
若編輯固定項目，已產生的歷史紀錄不自動覆蓋；已產生的未來紀錄也不會因停用自動刪除。

五、原私人資料轉家庭共用（請審慎操作）
1. 由每位私人資料擁有者自己登入 V2.1 → 設定 →「匯出我的舊私人資料」。
2. 確認 JSON 備份已下載並保存，再按「將我的私人資料轉入家庭」，二次確認。
3. 同一紀錄會使用固定轉入 ID 避免重複建立。私人原始資料先保留、不刪除。
4. 轉入完成後，全家能查看、修改及刪除共用內容。請先核對月份筆數與記事內容。
5. 這是資料公開給家庭成員的操作，不應替其他成員代操作。

六、資料匯入／匯出
設定 → 匯出 JSON、匯入 JSON、匯出 CSV；匯入 JSON 可選覆蓋或合併。
覆蓋時先觸發現有家庭資料備份，請確認檔案保存後再繼續；大量資料的匯入不是單一原子操作，請先於測試資料驗證。

七、權限與安全
維持現行 Firestore 安全規則；共用 bills/events/templates 的新增、修改對所有有效成員開放，刪除在 APP 採用軟刪除進回收區；管理者可還原。
私人資料只允許帳號本人存取；用戶端無法讀取其他家庭成員私人紀錄。
本包 firebase-config.js 為網頁端公開設定，不包含管理私鑰。勿將帳號密碼、Service Account 金鑰放入 GitHub。

八、更新後必測
(1) 管理者及家人登入；(2) 年度首頁顯示項目及未繳到期日；(3) 月份詳情金額、記事；
(4) 新增／修改／停用固定繳費；(5) 自動產生繳費不重複；(6) 成員同步；
(7) 備份與匯入；(8) 私人資料先匯出再移轉；(9) iPhone/iPad 螢幕顯示。
目前僅完成靜態語法與套件完整性檢查；Firebase 真實連線、跨裝置同步及實機 UI 需由使用者部署後驗收。
